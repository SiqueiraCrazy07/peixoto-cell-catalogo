# Peixoto Cell

Catálogo estático de telas, com busca, filtros por marca e linha, opções com/sem aro e orçamento pelo WhatsApp.

Publicação: GitHub Pages, branch `main`, pasta raiz. Sem instalação de dependências ou etapa de build.

Somente preços de venda estão neste repositório. Disponibilidade e instalação são confirmadas pelo atendimento.
